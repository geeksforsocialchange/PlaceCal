## Contributing

Want to start using PlaceCal, or know more about it? The [PlaceCal Handbook](https://handbook.placecal.org/) is your first stop.

Interested in getting involved in PlaceCal development? Jump into [Geeks for Social Change Discord](https://discord.gfsc.community/?ref=CONTRIBUTING.md) and join the `#placecal` channel, or email [support@placecal.org](mailto:support@placecal.org) for an induction.

## Code of Conduct

This project and everyone participating in it is governed by the [PlaceCal Code of Conduct](CODE_OF_CONDUCT.md), as well as GFSC's [Community Agreements](https://handbook.gfsc.community/community-agreements/) and [Safer Spaces Policy](https://handbook.gfsc.community/safer-spaces-policy/). By participating, you are expected to uphold these codes. Please report unacceptable behavior to [kim@gfsc.studio](mailto:kim@gfsc.studio).
